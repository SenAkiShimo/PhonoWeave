# PhonoWeave v9 — 自动声学结构发现实验

这次不是人工标注工具：两套模块都已在真实存档数据上自动运行。

- `phonoweave/native_acoustic_subtypes_v9.py`：使用冻结 v3 的 36 维声学上下文特征，在用户原有符号内部探索重复的声学差异。**这些特征的取样位置是 OTO 派生的，不是自动找到的音素。**
- `phonoweave/native_wav_motifs_v9.py`：直接读取 PCM WAV，依靠谱变化自动分段，并把频谱片段聚成未命名声学模式。**演示所用 168 条 WAV 为此前 OTO 实验生成的 600 ms 上下文片段，不是完整的 175 条原始录音。**
- `results/context/`：7,860 个 v3 声学样本、23 个原生符号的探索性分析；初步 `o` 模式因子声库混淆与留出模板不足被弃判，0 个标签取得可靠可拆分结论。
- `results/direct_wav/`：168 段真实短音频自动提取 503 个声学区域、2 个宽泛谱类型（336/167），**不是 2 个音素**。

没有 IPA 转换，没有新增 alias，没有修改原始音频，没有合并或拆分声库，也不要求用户补人工标注。这是算法研发和反例筛选，不是自动音素分割精度证明。

完整实验与方法限制见 `docs/native_acoustic_motifs_v9.md`。
